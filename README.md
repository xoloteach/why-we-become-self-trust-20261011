# Why You Don't Trust Yourself to Follow Through

Narration-led Why We Become episode plus three native vertical Shorts. Uses the supplied editorial stickman illustrations, 216 border-free panel layers, 133 phrase-timed scenes, semantic concept graphics, original ambient sound and word-highlight captions.

## Render
Install Python 3, FFmpeg, numpy, opencv-python-headless and pillow. Run `python audio.py` to reconstruct the mixed audio. Then `python motion.py --target longform --out out/final-longform.mp4`. Targets `short_01`, `short_02`, `short_03` render the corresponding portrait masters. Create `out` and `qa` first.

## Timing and provenance
Script preserved. Word timings are machine-assisted and eight recognized wording differences remain a listening-review limitation, not a claim of perfect alignment. Grid crops and panel use/omission are documented in the inventory. FSRCNN 4x reconstruction was applied to the actual supplied artwork, with a restrained Lanczos blend. Neural upscaling cannot restore guaranteed original detail.
